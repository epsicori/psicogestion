## Lecciones

### Propuestas para reglas (`.claude/rules/`)

1. **Supabase/RLS/definer**: guardan de rol (pasos 0-1) antes que lectura de tabla (paso 2). Comparar con H3 de diseño.
2. **Supabase/RLS/error sin lanzar**: nunca silenciar error con `coalesce` o `case`. Patrón crypt()+NULL.
3. **Zod/strictObject**: `'use server'` con strictObject rechaza entrada, fallando en cliente (Zod) no silenciosamente.

- Orden de guardas en exportar_nota: paso 0 antes de 1 antes de 2.

### Patrones para revisor
